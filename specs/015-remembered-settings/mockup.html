What to check

  • Create-game page: preset bar on top, "Reset to defaults" next to it; rules open and marked as changed.
  • The line about remembered computers explains why the computers appear later, in the lobby.
  • Lobby: the same two preset buttons for the host only; a preset applies computers and speed only, and a message names how many did not fit.
  • Start question (screen 11): only when the setup is neither an unchanged loaded preset nor the unchanged last setup. "No, start the game" starts as usual; "Save as preset" opens the normal dialog and then starts.
  • Presets are one dialog list with Load/Apply and delete (inline confirmation). No rename.

Not in this mockup

  • German texts, focus handling and keyboard behaviour, the nickname page (only a prefilled field, unchanged look), toasts.
  • Real PrimeNG components: the dialog, buttons and tags will follow the existing look.
