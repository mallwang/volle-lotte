What to look at

  • Slider: five steps, a higher value is faster (1 slow, 5 fast), step 3 is the default and marked. Today's pace is about step 2, so the slider reaches both faster and slower than today. The current step is named next to the label, so it can be read without the thumb position.
  • Guest view: same control, disabled, with the note "Only the host can change this." The current value stays readable.
  • Fast computer dice stays a separate switch under the same rules (host only, toast on change). The slider does not change dice roll time.
  • Toast: top right like the turn-result toasts, names the host, the setting and the new value. Dragging produces one toast after the thumb rests (try it as host; the preview toast on this page is for the host's own view of the demo).
  • Lobby: the setting sits in its own panel between the seats and the buttons, so hosts see it before pressing Start.
