What to check

  • "Rematch" is primary for the host, "Back to the lobby" stays secondary and always available.
  • Guests see "Rejoin" from the start, disabled until the host decided; no reload needed to activate it.
  • Reserved seats have a dashed outline and the label "Reserved, not back yet"; only the host can remove them.
  • Starting the game shows what happens to missing players ("drops Ben's seat").
  • Stale-round handling (FR-014/015) has no visible UI. Late requests are silently ignored.
