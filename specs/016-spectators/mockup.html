What to look at

  • Spectator table: same table, scores and log as the players, but no Throw/Bank buttons, and only the skip-dice-animation setting.
  • Counter ("👁 3 watching") sits next to the game title for players and spectators alike. Joining or leaving only changes this number; no log line, no toast.
  • Host settings gain one switch: Allow spectators. Off removes everybody and hides the counter. There is no spectator list (spectators are anonymous).
  • Stand-ins: dice are plain squares; the real table uses the existing dice area. Icons here are emoji; the real app uses PrimeIcons.
