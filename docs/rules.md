# Volle Lotte rules

Sources: Abacus game description (RWTH page), spielregeln-spielanleitungen.de, Java reference (`tmp/java/modernized`).
The sources agree on scoring and card effects. Differences are marked as **House rule** below.

## Fixed rules (not configurable)

- 6 dice. Scoring: a single 1 = 100, a single 5 = 50. Other single dice do not score.
- Three of a kind in **one** throw: 1s = 1,000, 2s-6s = face value x 100 (5s = 500). Combinations cannot be built across several throws.
- After every throw at least one scoring die must be set aside. Then the player either stops (banks the points) or throws the remaining dice again.
- A throw without a scoring die (bust): the turn ends and all points of the turn are lost (exception: Fireworks/Star).
- **Volle Lotte** (Tutto): all 6 dice score. The player may continue with a new card and 6 dice; the points collected so far stay in the turn (a bust loses everything).
- A turn starts by drawing a card. An empty deck is reshuffled (Java behaviour).
- Card effects:
  - **Bonus 200/300/400/500/600**: on Volle Lotte the bonus points are added.
  - **Double Lotte**: on Volle Lotte the points scored are doubled.
  - **Stop**: the turn ends immediately, the next player is up.
  - **Fireworks / Star** (same effect; Star is the extra card from the Java version): all scoring dice and combinations must be set aside. On a bust the points are **not** lost but credited. On Volle Lotte no new card is drawn and play continues with 6 dice.
  - **Street**: collect dice showing 1-6. Success: 2,000 points, otherwise 0.
  - **Plus/Minus**: on Volle Lotte +1,000 for the player, the leader(s) lose 1,000 (a leading player loses nothing).
  - **Clover** (only 1 card): reaching Volle Lotte twice in a row wins the game immediately.
- Game end: a player reaches the target score, or wins via Clover.
- Dice and the card deck are generated by the server only.

## Configurable rules (set at game creation, defaults)

| Rule                                                   | Default                                          | Source                |
| ------------------------------------------------------ | ------------------------------------------------ | --------------------- |
| Target score                                           | 6,000 (free choice, e.g. 10,000)                 | sources               |
| Minimum points to bank                                 | 350 (0 = off)                                    | **House rule** (Java) |
| Four or more of a kind: each further equal die doubles | on                                               | **House rule** (Java) |
| Number of cards per type                               | default set below                                | sources               |
| Finish the round when the target score is reached      | off                                              | open decision         |
| A player leaves                                        | host decides: put in a computer or free the seat | new                   |

### Default set (56 cards)

Bonus 200/300/400/500/600 5 each (25), Double Lotte 5, Stop 10, Fireworks 5, Street 5, Plus/Minus 5, Clover 1.
**Star** stays as its own card type. Open: in addition to the 5 Fireworks (57 cards) or instead of one of them? (see clarification questions)

## Clarification questions for `/speckit-clarify` (sources are silent)

1. Star: one of the 5 Fireworks cards or an additional card? Own count in the card configuration?
2. Stop after a Volle Lotte in the same turn: are the points collected so far kept (proposal: yes, credited)?
3. Double Lotte: does it double only the points since this card or all points of the turn (proposal: only since this card)?
4. Street: do throws count cumulatively (one die per value, across several throws)? Is a bust a throw without any still-missing value? Do the turn points before it count?
5. Plus/Minus: can the score become negative (proposal: no, floor at 0)? Do several leaders all lose?
6. Clover: do the points of both Lottes count? Do they vanish on a bust as usual?
7. Minimum 350: does it apply to the turn total including bonus when banking, also after a Volle Lotte?
8. Fireworks: is the bonus dropped on Volle Lotte (source: no new card, no bonus)?
9. Target score reached: game ends immediately or finish the round (source: immediately)?
10. Tie-break and ranking at game end.
